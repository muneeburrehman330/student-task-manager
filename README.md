# Student Task Manager

## Project Description

Student Task Manager is a simple web-based project designed to help students manage their tasks. It allows users to add tasks and search for tasks easily. The project was developed as part of a Git and GitHub collaborative assignment to practice version control and teamwork.

## Git Workflow

The project was developed using a collaborative Git workflow:

1. Created a local Git repository.
2. Created the initial project files.
3. Created feature branches for different tasks.
4. Modified files on separate branches.
5. Committed changes with meaningful commit messages.
6. Pushed branches to GitHub.
7. Created Pull Requests.
8. Reviewed Pull Requests.
9. Merged approved Pull Requests into `main`.
10. Created and resolved a merge conflict.
11. Used Git Stash, Restore, Reset, and Revert.
12. Created a version tag and GitHub Release.

## How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project folder:

```bash
cd student-task-manager
```

3. Open `index.html` in a web browser.

The project can also be opened directly by double-clicking `index.html`.
